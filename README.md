# Portafolio de Sara Márquez

Página de una sola pantalla con animación 3D (cámara y lente pastel) que acompaña el scroll, una cinta de película con 6 videos y una sección "Ver más videos".

- `index.html`: toda la página (estilos, contenido y animación).
- `js/three.min.js`: librería 3D (three.js r149).
- `videos/` y `img/`: videos comprimidos a 720p y sus imágenes de portada.

Es un sitio estático: no necesita instalación ni build. En Vercel se despliega tal cual (Framework: Other, sin comando de build).
